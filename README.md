# ShopLite

A learning project: a Java backend for a small e-commerce shop.
Currently a command-line app; growing into a Spring Boot REST API with PostgreSQL.

## Requirements
- JDK 21
- Git

## How to run
    git clone https://github.com/hanlamhuy2000-gif/shoplite.git
    cd shoplite
    javac Main.java
    java Main
